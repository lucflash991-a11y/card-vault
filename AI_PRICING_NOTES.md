# AI Market Pricing

v1.1.8 uses the existing Gemini API key with Google Search grounding. It searches current public web sources for the exact identified card, returns a conservative estimate/range/confidence, and sends grounding source links back to the Card Vault UI. This is an AI web estimate, not an official eBay sold-price average. When eBay API access is approved, official marketplace comparables can be combined with this layer.
